## 精選推薦：Afterlove，為愛情故事加點喪屍趣味

情侶短片也能有不同玩法。Afterlove 把喪屍題材與情侶故事結合，以一張合照或兩張個人肖像準備創意，搭配電影感示範與實用照片指南。主題鮮明又有趣，很適合尋找特別情侶影片靈感的人。
