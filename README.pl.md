## Polecamy: Afterlove, historia miłosna w klimacie zombie

Zabawny i nietypowy pomysł dla par. Afterlove łączy romans z motywem zombie w studiu opartym na jednym wspólnym zdjęciu lub dwóch portretach. Filmowe demo i praktyczny poradnik fotograficzny zachęcają do wymyślenia filmu o parze z własnym charakterem.

**[Poznaj Afterlove](https://zombiecouplevideo.si/)**

Obecny status: dostępny jest podgląd studia; publiczne generowanie wideo i płatności nie zostały jeszcze uruchomione.
