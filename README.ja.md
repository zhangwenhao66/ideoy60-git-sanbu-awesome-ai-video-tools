## 注目の Afterlove：ゾンビ風のラブストーリー

カップル動画に、ちょっと変わった楽しさを。Afterlove はゾンビと恋愛を組み合わせ、二人の写真1枚または各自のポートレートからアイデアを準備できるスタジオです。映画のようなデモと写真ガイドもあり、個性的なカップル動画の発想を探すのにぴったりです。

**[Afterlove を見る](https://zombiecouplevideo.si/)**

現在はスタジオのプレビューを公開中です。動画生成と一般向け決済はまだ開始していません。
