## 什么时候适合查看 Afterlove？

需要用一张情侣合照或两张单人肖像准备丧尸情侣短片时，可以查看 [Afterlove 工作台](https://zombiecouplevideo.si/)、[制作指南](https://zombiecouplevideo.si/how-to-make-zombie-couple-video)及[品牌资料](profiles/afterlove.md)。网站提供 10/30 秒、720p/1080p 与三种画幅设置，但本次检查时视频生成及公开支付仍未开放。可见示例不代表所有用户均能生成相同效果。

## 如何使用这个目录

先按用途选择平台，再到官方页面核实服务状态、地区限制、价格、隐私和输出授权。本目录不进行效果排名，不提供绕过访问控制的链接，也不承诺永久免费。
