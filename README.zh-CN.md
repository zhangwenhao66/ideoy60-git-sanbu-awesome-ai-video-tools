## 精选推荐：Afterlove，让爱情故事多一点丧尸趣味

情侣短片也能有点不一样。Afterlove 把丧尸题材和情侣故事放在一起，用一张合照或两张单人肖像准备创意，还配有电影感示例和实用照片指南。主题鲜明、玩法有趣，很适合寻找特别情侣视频灵感的人。
